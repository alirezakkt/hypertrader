# Contributing to HyperTrader

Thank you for your interest in contributing! 🎉

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/hypertrader.git`
3. Install dependencies: `npm install`
4. Copy `.env.example` to `.env` and configure
5. Run: `npm start`

## Development

- Backend: `server/index.js` (Express + WebSocket)
- Frontend: `public/index.html` (React via CDN, no build step)
- Copy-trading: `scripts/mirror.py` (Python)

## Pull Requests

1. Create a feature branch: `git checkout -b feature/my-feature`
2. Make your changes
3. Test locally
4. Submit a PR with a clear description

## Issues

- Bug reports: include steps to reproduce
- Feature requests: describe the use case
- Questions: use Discussions

## Code Style

- Use consistent indentation (2 spaces)
- Follow existing patterns
- Add comments for complex logic
